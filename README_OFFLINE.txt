IUS AND SONS — OFFLINE EDITION
==============================

1) USE ON A PC (no internet needed)
   - Unzip this folder anywhere (e.g. Desktop). Keep all files together.
   - Double-click  index.html  (opens in Chrome or Edge — recommended).
   - Register your school, then sign in. Everything works without internet.

2) INSTALL AS AN APP (PC, Android phone, iPhone)
   An installed app opens in its own window with its own icon and works offline.
   - Put this folder online once (free): https://app.netlify.com/drop  -> drag the folder in.
   - Open the Netlify link:
       PC (Chrome/Edge): click the "Install" icon at the right of the address bar.
       Android (Chrome): menu (⋮) -> "Install app" / "Add to Home screen".
       iPhone (Safari): Share -> "Add to Home Screen".
   - After the first visit it keeps working with no internet.

3) YOUR DATA — IMPORTANT
   Data is stored ONLY inside the browser/app on that device.
   - Clearing browser data, or switching browser/PC, loses it.
   - Dashboard -> School Profile -> "Download Backup" regularly; keep the file on a USB/Drive.
   - To move to another device: open the site there, register any temporary school,
     then Dashboard -> School Profile -> "Restore Backup" and pick your file.

4) NOTES
   - Platform Admin (admin.html) only sees schools registered on the same device.
   - Want sign-in from many devices with shared data? Use the Online Edition (Supabase).
